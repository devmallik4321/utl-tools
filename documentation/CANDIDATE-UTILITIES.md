# UTL.tools — Candidate Utilities Discovery & Expansion Pipeline (V1.1)

This prioritized registry identifies evergreen, high-utility, and high-search-intent candidates for future batch releases. All candidates adhere to the **Static-First Principle**: 100% client-side execution, low maintenance, zero subscriptions, and instant problem-solving.

---

## 🎯 Priority Classification Framework

- **P0 (Build Immediately)**: High search volume, high daily utility, purely browser-native execution, zero maintenance.
- **P1 (Strong Candidate)**: Substantial demand, high evergreen value, straightforward client-side implementation.
- **P2 (Later Release)**: Specialized domain utility, moderate search volume, niche professional value.
- **P3 (Advanced / Server-Dependent)**: Requires backend infrastructure, API proxies, headless browser, or cloud runners (scheduled for future platform horizons).
