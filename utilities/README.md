# Standalone Utilities Directory

This directory houses modular, reusable, framework-independent utility code organized by domain:

- `/network`: IP, DNS, ping, browser inspectors, and connectivity tools.
- `/developer`: JSON formatters, validators, Base64 engines, UUID generators, timestamps, and URL tools.
- `/business`: QR code generators, email signatures, startup name ideation, and invoice engines.
- `/finance`: Compound interest, loan amortization, percentage, and discount calculation engines.
- `/health`: BMI, chronological age, and daily hydration calculators.
- `/education`: Word counters, reading speeds, and 4.0 GPA calculation algorithms.
- `/creative`: Color space converters and aspect ratio dimension engines.
- `/fun`: Cryptographic RNGs, decision wheels, 3D coin flips, polyhedral dice, and password generators.
- `/ai`: Token estimation, prompt structuring, and LLM pricing estimators.

Each utility is designed according to the **Static-First Principle**: 100% client-side execution, minimal external dependencies, and evergreen operation.
